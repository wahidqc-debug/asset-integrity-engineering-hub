Pressure test reference calculation

UG-99(b) hydrostatic and UG-100 pneumatic reference factors. Enter independently verified MAWP and the lowest applicable allowable-stress ratio at test versus design temperature. Not an authorization to test; static head, component stress limits, test configuration and applicable exceptions require separate review.

Pneumatic testing involves substantial stored energy. Use an approved test procedure and safety controls.

Internal volume and liquid inventory

Ideal internal geometry: vertical cylindrical vessel with identical heads at both ends. Straight shell length excludes heads. No internals, nozzles or straight flange additions.

Nozzle neck thickness — UG-27 / UG-45 screening

Choose nominal dimensions as a starting point only. Verify dimensions and allowable stress against the applicable code edition. Enter the design inside radius in the corroded condition; the nominal radius is not automatically a design radius.

UG-45 additional minimum must be determined independently for the applicable nozzle type, code edition and exceptions. Enter on the same net thickness basis. No automatic UG-45 table or allowable stress lookup is provided.

Code assessment preparation

UG-37 — Opening reinforcement

Collect shell and nozzle required and available thicknesses, opening diameter, material stress ratios, reinforcement limits, weld details, pad dimensions and corrosion allowances. Verify all applicable opening rules and load cases. No reinforcement area calculation implemented.

UG-28 / UG-33 — External pressure

Collect outside diameter, effective unsupported length, available thickness, stiffener details, head geometry, material and temperature. Obtain applicable external pressure charts and factors from the governing code. No allowable external pressure calculation implemented.

UCS-66 — MDMT

Collect material specification and curve assignment, governing thickness, weld details, heat treatment, stress ratio and impact-test records. Evaluate exemptions and reductions using the applicable code edition. No MDMT determination implemented.

Do not enter confidential asset data. All calculations run locally.
